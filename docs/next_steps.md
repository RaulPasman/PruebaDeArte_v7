# Próxima etapa — Friends & Family

El MVP de implementación está cerrado. Las tareas siguientes requieren evidencia externa al código:

1. Preparar las imágenes locales con `DESCARGAR_IMAGENES.bat` y validar con `tools/validate_images.py`.
2. Abrir el prototipo desde `ABRIR_PRUEBA_DE_ARTE.bat` y completar algunos recorridos manuales.
3. Compartirlo con usuarios reales y observar dónde dudan, abandonan o comentan.
4. Registrar qué obras generan elecciones demasiado obvias o poco útiles.
5. Ajustar pesos, duelos y recomendaciones con esos datos, no antes.
6. Validar las 60 imágenes desde el hosting definitivo; si alguna URL falla, sustituirla por un archivo local/CDN estable.
7. Revisar derechos/licencias antes de cualquier publicación abierta.

La conexión comercial con galerías, artistas o talleres permanece fuera de esta versión.
