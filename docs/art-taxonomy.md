Cada obra contiene un vector de ocho ejes, metadatos básicos y un texto breve de observación. Los textos de contexto priorizan qué mirar antes que una explicación académica extensa.

Las imágenes usan URLs candidatas de Wikimedia Commons/instituciones. La versión F&F puede utilizar esta estrategia; antes de una publicación abierta conviene validar cada archivo, resolución y estabilidad.
